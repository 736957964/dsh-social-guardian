# 模块架构与数据流规范

## 1. 情绪状态机 (Emotion State)
- **触发源**：时钟事件（24小时昼夜节律感知）与群聊交互刺激；
- **状态计算**：`calculateMood(hour, config)`，白天（7:00-23:00）维持高元气值（默认86），深夜自动切换微困值（默认70）；
- **持久化**：`emotion-state.json`，支持外部参数热修改。

## 2. 群友好感度账本 (Affection Ledger)
- **成长规则**：每日初次互动自然增长 1 点，自然成长上限 80 点；
- **特权机制**：管理员天然满分锁死，并具备赦免/重置接口；
- **展示形态**：结构化数据透出，支持调用本地渲染器生成卡片。

## 3. 看门狗守卫 (Watchdog Guardian)
- **超时保护**：默认 180 秒会话卡死熔断；
- **锁释放**：在超时或进程中断时强制清除僵尸锁；
- **唤醒安全**：保证会话在收尾时具备保底唤醒条件，杜绝永久假死。

## 4. 全局记忆审计 (Memory Inspector)
- **索引**：读取会话历史、群友印象与审计轨迹；
- **检索**：支持关键词扫描与历史变更回溯。
